# 官方 Web Host 浏览器验收

日期：2026-09-30。基线 `d1322fc`；新增 [Web Host Lab](../../labs/web-host-lifecycle/README.md)。npm DSH `0.1.7-rc.2`，固定源码 `477b4f420553e8a52c2fbccc464d7561b239c443`；macOS arm64、Node `26.7.0`、pnpm `12.3.4`、agent-browser `0.37.0` / Chromium。

## 运行范围

公开 `dsh --profile web`，独立 home/workspace，使用上游网页内目录选择器 overlay。通过浏览器确认内测声明、添加临时工作区、检查模型选择、发送两轮任务、查看轨迹、刷新页面，并在两轮之间停止和重新启动 Host。保持 Web 自身 Session Controller、认证和事件 transport，不加入 SDK resume adapter。

UI 模型名称为 `DeepSeek-V41-Flash / High`，持久请求配置为 `deepseek-official / deepseek-flash / high`，`maxTokens: 256000`。模型路由证据与显示名称分别记录，不据名称推断底层其他版本。真实对话只执行两个用户 turn；标题等 Web 辅助请求不据此计为零，也没有推算供应商总费用。

`checkpoint` 和 `final` 在对应 Host 退出后用独立公开 JSONL backend 读取 V4，并检查工具 call/result/turn 对应关系；文件由原生 Bash 工具产生。官方 Bash 的说明字段 `description` 被允许，实际 `command` 仍严格相等。

上游 `process-shutdown.ts` 的 5 秒 disposal timeout 和失败路径也可使用同一中断码。因此 130 本身不是清理成功证据；本次结论依赖随后的公开 backend 重读与 PID 核对，不扩大到整个 runtime 的任意资源。

## 实时与持久输出

CDP 仅记录路径、类别、长度和到达时间。观察到 `/api/remote.mux` WebSocket，以及 `/api/session/prompt`、`/api/session/list` 等 unary POST。第一轮最终文本的 4 个独立 `assistant-stream / text-delta` 帧在 `1790760504630–1790760504641` ms 到达；对应持久 `assistant/message` 在 `1790760504660` ms 到达。第二轮也是 4 帧，分别为 `1790760754887–1790760754891` 和 `1790760754906` ms。

两组增量均先于各自的 committed message。这里只证明一次顺序对话中浏览器收到了独立实时帧，不测量每一帧的视觉呈现、每 token 延迟或网络拥塞下的保证。历史重放中的内嵌 chunk 未算成实时帧。安全元数据见 [JSON](../../labs/web-host-lifecycle/evidence/2026-09-30.json)，截图只保留最终对话，不含认证信息或模型推理内容。

实跑使用本地 CDP 收集脚本，保留类别、路径、时间和 payload 的字符串长度；长度未参与实时顺序结论。Lab 中提供的便携观察器进一步收紧类别白名单，将长度字段明确命名为 `payloadCodeUnits`，已做 syntax/lint 检查，未用它重新调用模型。

## 开发和验证

前两次启动因 CLI 参数顺序失败，在模型任务开始前退出；最终改为显式 `--profile web --patch …` 后再传 Web 参数。没有通过修改 upstream 或替换 Web Host 避开启动问题。

验收器先用占位实现运行失败测试，再加入 URL 去 token、精确命令和终态检查。官方 Bash `description` 的接受路径补了 RED/GREEN；独立 review 指出的“停止期间任意非零退出被忽略”也补了 RED/GREEN，现在仅 code 0 或主动 SIGINT 的 130 可成功。此分类修改没有重复模型调用。

## 尚未覆盖

正常 SIGINT 后的恢复不是 SIGKILL/crash recovery；同端口已有 cookie 可用不是完整认证/Host/Origin 安全审计。没有覆盖 cancel/approval 交互、断网中的写操作、重复投递、多租户授权、Web 全功能、跨平台或性能基准。SDK/ACP 的语义仍分别以各自 Lab 为准。
