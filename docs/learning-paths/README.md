# 选择一条学习路线

如果希望完整走一遍，打开[全章导航](chapters.md)。如果已经有明确目标，可以选下面一条路线，从最小运行逐步进入应用和机制。

- [Python App Builder](python-app-builder.md)：先连续完成两轮对话，再接入 FastAPI，最后让业务任务和产物经得起服务重启。
- [TypeScript Runtime Builder](typescript-runtime-builder.md)：先理解协议的完成信号，再管理 runtime、开发插件，并将结果接到 React/AG-UI。
- [DSH Internals Reader](../../how-dsh-works/README.md)：从 plugin tree、Inbox 和工具执行，追到日志、压缩、child 与客户端协议。

三条路线已有对应代码与限定场景验证。完成基础后，[工程化七课](engineering.md)继续处理超时、容量、身份、隔离、观测、eval 和跨引擎差异；容器与恢复扩展也已给出明确实验。具体完成范围由[验收索引](../reviews/2026-10-01-chapter-audit.md)维护。
