# Projects

计划中的方向：

- CopilotKit + AG-UI ↔ DSH Runtime
- TypeScript full-stack Agent 应用
- 带业务 Conversation / Run / Artifact 状态的 Agent 服务

可复用适配器先留在第一个真实项目中；只有出现第二个消费者时再提取，避免为了目录整洁过早抽象。
