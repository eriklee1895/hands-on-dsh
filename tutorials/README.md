# Tutorials

这里保存有明确起点、章节顺序和完成结果的系统教程。

## 已实现

- [Python SDK](python-sdk/README.zh.md)：固定 Python `0.1.5rc1`，从高层 SDK 到裸 JSON-RPC 的 6 个练习。
- [FastAPI 101](fastapi-101/README.md)：仍固定 Python `0.1.1rc1`，从同步 API 到 SSE、工具轨迹和 runtime 生命周期。
- [TypeScript SDK](typescript-sdk/README.md)：固定 npm `0.1.7-rc.2`，公开 profile、高层/底层 client、committed notification 投影和 receipt-to-idle 的 4 个练习。

教程可以跨越 SDK、协议和 runtime 概念。某个概念需要更小、更可控的验证时，链接到 `labs/`；需要解释 DSH 源码时，链接到 `how-dsh-works/`。
